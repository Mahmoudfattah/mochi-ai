# Project handoff

## Current state

- Planning phases 0 through 6 are complete.
- Milestone M0 (Foundation) is implemented: repository structure, tooling, CI,
  design tokens, self-hosted fonts, config defaults, app shell, and community
  files.
- No character, voice, Supabase, or conversation features have been started.
- The foundation check page uses persona config, Arabic copy, Western digits,
  and local fonts.

## How to read the docs

Start with [`00_VISION.md`](./00_VISION.md) for product intent and approved
decisions. Use [`06_SCOPE_AND_ARCHITECTURE.md`](./06_SCOPE_AND_ARCHITECTURE.md)
as the current scope and architecture source, [`04_DESIGN_SYSTEM.md`](./04_DESIGN_SYSTEM.md)
for design rules, and [`design/tokens.css`](./design/tokens.css) for the original
design token source. Read the milestone table in the architecture document
before proposing implementation work. `ARCHITECTURE.md` is retained for history
and is superseded.

## Milestone approval

Each milestone requires the founder's review and approval before the next
milestone starts. Keep changes limited to the currently approved milestone.
M0 must be accepted before beginning M1.

## Next step
